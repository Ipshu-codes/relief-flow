# Rahat

Unified Flutter + FastAPI disaster relief coordination with local Ollama AI,
verified volunteers, supply confirmation and offline SOS retry.

**Start here: [Complete setup and submission guide](docs/README.md).**

```powershell
.\start.ps1 -Setup -Demo -Build
```

Requires Python and Flutter on PATH. Opens the unified app at
http://127.0.0.1:8000/ after startup.

The original `Rahat-A-disaster-response-platform/` folder is preserved.
The active implementation is `backend/`, `frontend/`, `ai/` and `protocol/`.
See [integration inventory](docs/INTEGRATION.md) and
[honest limitations](docs/LIMITATIONS.md) before demonstrating.
